# Day-0 Manual Checklist

- [ ] Photograph external chassis and ports.
- [ ] Photograph BIOS / UEFI pages (F10).
- [ ] Ensure Windows Updates are paused or disconnected initially.
- [ ] Run Pass 1 Capture (Elevated).
- [ ] Verify `CAPTURE-COMPLETE.txt` and `SHA256SUMS.tsv`.
- [ ] Run Pass 2 Capture (ExportDrivers/Firmware) if needed.
- [ ] Verify BitLocker status.
- [ ] Do NOT open chassis on Day 0.
