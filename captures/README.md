# Hardware Captures

This directory is intended for parsed metadata or evidence summaries.

**DO NOT COMMIT RAW OR PRIVATE CAPTURE DIRECTORIES HERE.**
The output generated by `day0-capture.ps1` often contains proprietary Windows drivers, firmware blobs, and unique machine identifiers (serials/UUIDs).

## Workflow
1. Run `day0-capture.ps1` on the target Windows machine.
2. Transfer the capture directory to your Linux development host.
3. Run `scripts/linux/analyze-day0-capture.py --capture /path/to/capture`.
4. Review the generated reports in `analysis/`.
5. Only commit curated, redacted evidence snippets (e.g., hardware IDs) to the repository.
