# HP-published firmware for the OmniBook 5 16-bf1xxx

These files come unmodified from HP's Qualcomm chipset driver pack for this
model: package `QCSCT1.1Q_AAN2B2`, build `4500.X6` (`P01AN2B2`), which HP
publishes for download. The owner approved committing them. Only the files
Linux needs are here; the full 1.8 GB pack stays in the ignored
`qualcomm-driver-pack/` directory. `MANIFEST.tsv` lists the SHA-256 and size
of every file. Each directory also keeps the package's INF, whose `DriverVer`
line identifies the version.

| Directory (HP package) | DriverVer | Files | Linux use |
|---|---|---|---|
| `qcbluetooth8480_WHQL` | 00685.13804.00030.00000 | `clnbtfw10.tlv`, `clnbtnv10.bin`/`.b*`, `BSRC_BT.bin` | QCC2072 ("Colorado") Bluetooth patch and NVM. `btqca` names this chip Orion and loads `qca/ornbtfw<rom>.tlv` and `qca/ornnv<rom>.b<board>`. linux-firmware ships only ROM 0x11 (`ornbtfw11.tlv`). |
| `qcuart8480` | 00685.13804.00030.00000 | `BSRC_UART_*Wire_*.bin` | PEP power recipes for every QUP UART. `UR15` (Bluetooth) steps `gcc_qupv3_wrap1_s6_clk` through 7.3728–100 MHz and uses GPIOs 56–59. Decode with `scripts/linux/parse-bsrc.py`. |
| `qcwlancol8480_Enable_WHQL` | 00685.13804.00040.00010 | `bdwlan_qcc2072_1p0_ncm820A.elf` | QCC2072 Wi-Fi board data; `scripts/linux/ath12k-board-add.py` adds it to `board-2.bin` for subsystem `103c:8ef3`. |
| `qcsubsys_ext_adsp8480_4500R_HDCP_WHQL` | 00685.13804.00050.00009 | `qcadsp8480.mbn`, `adsp_dtbs.elf`, `adsp*.jsn` | HP-signed ADSP image, needed for PMIC GLink (battery, USB-C, RTC) and audio on the device-tree path |
| `qcnspmcdm8480` | 30.0.220.11010 | `qccdsp8480.mbn`, `cdsp_dtbs.elf` | HP-signed CDSP image |
| `qcdx8480` | 32.0.146.0 | `qcdxkmsuc8480.mbn`, `qcvss8480.mbn`, `qcav1e8480.mbn` | GPU zap shader and video firmware |

Board data that is built from these files, such as `board-2.bin`, is
regenerated by scripts rather than committed.
